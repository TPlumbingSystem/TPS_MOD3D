# TAIÓ — Modelo 3D Interativo

Cubão 3D (Plotly, HTML autônomo) com topografia real, corpos intrusivos (sill/dique),
formações sedimentares e ferramenta de corte com 4 direções — sistema intrusivo de
Taió (SC), Mestrado em Geologia, UFSC.

Abra `viewer_3d_taio.html` direto no navegador.

Identidade visual TAIÓ — Sistema Intrusivo · Plumbing System. Complemento dos outros
produtos: [TPS_HUB](https://github.com/TPlumbingSystem/TPS_HUB) (página inicial),
[TPS_SEC2D](https://github.com/TPlumbingSystem/TPS_SEC2D),
[TPS_DASH](https://github.com/TPlumbingSystem/TPS_DASH),
[TPS_WEBM](https://github.com/TPlumbingSystem/TPS_WEBM).

Gerado por `gerar_visualizador_3d.py` (Python, Plotly/GeoPandas) — depende dos dados
do projeto completo (topografia, polígonos de campo, litologia CPRM), não roda de
forma standalone fora dessa estrutura; incluído aqui como referência/histórico do código.
